# Indonesia Monetary Transmission & Financial Depth Analysis

An empirical econometric project analyzing the lag and directionality between Money Supply (M2) and Private Credit (DCP) in Indonesia and ASEAN-6 using Vector Autoregression (VAR) and Forecast Error Variance Decomposition (FEVD).

## Key Results
- **M2 -> Credit Lag:** 1-year lag ($p = 0.0317$)
- **FEVD Variance Explained:** M2 explains 21.3% of Credit variance; Credit explains 7.1% of M2 variance.
